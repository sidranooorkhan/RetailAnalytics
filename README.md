# RetailAnalytics

### Customer Purchase Behaviour Analysis and Segmentation

## Overview
RetailAnalytics is a data analytics and machine learning project that explores customer purchasing behaviour using the Online Retail dataset.

The project applies RFM (Recency, Frequency, Monetary) analysis and K-Means clustering to identify distinct customer segments and generate meaningful business insights.

## Objectives
- Analyse retail transaction data.
- Perform data cleaning and exploratory data analysis.
- Understand customer purchasing patterns using RFM analysis.
- Segment customers using K-Means clustering.
- Identify business opportunities through customer insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology
1. Data Loading and Cleaning
2. Exploratory Data Analysis (EDA)
3. RFM Analysis
4. Feature Scaling
5. K-Means Clustering
6. Customer Segmentation and Business Insights

## Dataset
[UCI Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail)

## Key Findings
- Analysed 4,338 identified customers.
- Identified four customer segments.
- High-value customers represented 16.44% of customers and contributed 64.89% of identified-customer revenue.
